Welcome to the **Git and GitHub Foundations** course repository! This course is designed to take you from a complete beginner to a confident collaborator using the world’s most popular version control toolset. The curriculum aligns closely with the official **[GitHub Foundations (GH-900) Certification Exam](https://github.com)** domains.

## 🎯 Course Overview
This course provides a comprehensive, hands-on introduction to **Version Control Systems (VCS)** using **Git** and **GitHub**. You will learn how to track code changes locally, manage complex codebases, and effectively collaborate with engineering teams around the globe.

By the end of this course, you will be equipped to manage repositories, automate workflows, and comfortably sit for the official GitHub certification.

## 📚 Course Modules & Curriculum

### Module 1: Introduction to Version Control & Git Basics
* **Concepts:** Local vs. Distributed Version Control Systems.
* **Git Mechanics:** The internal object model, the `.git` folder, and the "Three Trees" (Working Directory, Staging Area, Local Repository).
* **Core Commands:** `git init`, `git status`, `git add`, and `git commit`.

### Module 2: History Inspection & Safe Recovery
* **Navigation:** Reading `git log`, checking out historical commits, and navigating a "detached HEAD" state.
* **Undoing Changes:** Safely managing mistakes using `git restore`, `git revert`, and recovering lost work via the `git reflog`.

### Module 3: Branching & Advanced Merging
* **Isolation Workflows:** Creating, switching, and deleting local branches (`git branch`, `git checkout`).
* **Integration:** Feature integration strategies — `git merge` vs. `git rebase`.
* **Conflict Resolution:** Identifying and resolving merge conflicts systematically.

### Module 4: GitHub Integration & Remote Collaboration
* **Remotes:** Configuring remote links (`git remote`), using `git push`, `git pull`, and `git clone`.
* **The GitHub Flow:** Forking, creating Branches, opening **Pull Requests**, and managing code review loops.
* **Repository Essentials:** Setting up `.gitignore` rules, writing highly effective `README.md` files with Markdown, and configuring `LICENSE` files.

### Module 5: Modern Dev Practices & Project Management
* **DevOps Essentials:** Introduction to automation with **GitHub Actions** workflows.
* **Project Management:** Organizing team deliverables using **GitHub Issues** and **GitHub Projects** boards.
* **Privacy & Governance:** Branch protection rules, `CODEOWNERS` definitions, and basic security best practices.

## 🛠️ Toolchain Prerequisites
To actively participate in the labs and exercises, you must install the following utilities on your local machine:

1. **Git CLI:** Download and run the latest installation package for your OS via the official [Git Downloads Platform](https://git-scm.com).
2. **Text Editor:** We recommend downloading [Visual Studio Code](https://visualstudio.com).
3. **GitHub Account:** Sign up for a free cloud account on [GitHub](https://github.com).
   * *Tip for Students:* If you are currently enrolled in an academic program, apply for the student developer package at [GitHub Education](https://github.com) to unlock free certification vouchers and partner benefits.
